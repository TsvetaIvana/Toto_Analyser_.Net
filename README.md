# 🎱 Тото Анализатор

Конзолно .NET приложение за изтегляне и статистически анализ на исторически данни от лотария **Тото 2 (6x49)**, публикувани на официалния сайт на [Спорт Тото](https://info.toto.bg/statistika/6x49).

***

## 📋 Описание

Приложението изтегля реални тиражи от 1958 г. до днес, разпознава различни формати на файловете и предоставя интерактивен статистически анализ с ASCII визуализации директно в конзолата.

***

## ⚙️ Технически изисквания

* .NET 8 или по-нова версия
* NuGet пакет: `DocumentFormat.OpenXml` (за четене на DOCX файлове)

***

## 🗂️ Структура на проекта

```
Toto_Analyser/
├── DataLoader.cs     # Изтегляне и парсване на данни (TXT и DOCX)
├── Statistics.cs     # Статистически анализ с LINQ
├── Visualizer.cs     # ASCII визуализации в конзолата
├── LotteryDraw.cs    # Модел на един тираж
├── Program.cs        # Входна точка и интерактивно меню
└── TotoData/         # Локален кеш на изтеглените файлове
```

***

## 🚀 Функционалности

### Модул 1 – Зареждане на данни

* Изтегля автоматично всички налични файлове от сайта чрез `HttpClient`

* Поддържа **три различни формата** на входните файлове:

  * **Формат А** (1958–2014): `0,8,12,25,31,40,42` – CSV без заглавие
  * **Формат Б** (2015–2017): `1 2, 5, 8, 10, 26, 31 1, 19, 31, 32, 36, 48` – таблица с табулации, поддържа множество тегления
  * **Формат В** (2018–2025): `Тираж 1/2020, Теглене 1: 8 18 27 45 47 49` – текстов формат с кирилица

* Кешира файловете локално в папка `TotoData/` и работи и в **офлайн режим**

* Поддържа файлове в **TXT** и **DOCX** формат

### Модул 2 – Статистически анализ (LINQ)

* **Топ N най-чести числа** – кои числа са изтеглени най-много пъти
* **Горещи двойки** – кои две числа най-често се падат заедно в един тираж
* **Разпределение по десетици** – брой изтегляния в диапазоните 1–10, 11–20, 21–30, 31–40, 41–49

### Модул 3 – Визуализации

* **Bar Chart** – хоризонтална ASCII лентова диаграма, нормализирана спрямо максималната стойност

* **Heat Map 7×7** – числата 1–49 наредени в мрежа, оцветени по честота:

  * 🔴 **Червено** – горни 30% (горещи числа)
  * 🟡 **Жълто** – средни 40% (неутрални числа)
  * 🔵 **Циан** – долни 30% (студени числа)

### Модул 4 – Интерактивно меню

```
==============================================
              ТОТО АНАЛИЗАТОР               
==============================================
   [1]  Избери период (от година - до година)
   [2]  Топ N най-чести числа
   [3]  Горещи двойки
   [4]  Разпределение по десетици

   [0]  Изход
==============================================
```

* Изисква първо избор на период преди анализ
* Пълна валидация на входа – приложението не се срива при невалидни стойности

## ▶️ Стартиране

```bash
git clone <repository-url>
cd Toto_Analyser
dotnet run
```

При първо стартиране приложението изтегля всички файлове от сайта и ги кешира локално. При следващи стартирания се използва кешът, освен ако не са налични нови файлове.
